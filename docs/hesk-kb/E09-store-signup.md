# Self-serve store signup

Operators turn public signup on or off under Admin → Signup. It starts off.

When on, Create your store asks for the store name, owner email, and password. The web address is built from the store name. Passwords must be at least eight characters and match the confirmation. Too many tries from one address are refused for an hour.

Signup creates the mall the same way the command-line provisioner does. If creation fails, nothing half-built is left behind. After success, the owner is signed in to that mall.
