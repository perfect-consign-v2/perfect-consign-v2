# Promo codes

Owners create redeemable codes under Promo codes. Each code is unique per mall (case-insensitive), percent or amount, with optional start/end dates and a max use count.

Cashiers open Promo on the register and enter the code. Invalid, expired, inactive, or used-up codes are refused — they are never silently ignored. A promo becomes the ticket discount with reason promotion. Clear any other ticket discount first. The cashier discount ceiling still applies.

Uses increment only when the sale posts. Voiding a sale does not give the use back. Delete a code only if it has never been used; otherwise deactivate it.
